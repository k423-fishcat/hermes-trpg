## 八、结论

系统核心功能（战斗、法术、检定）工作正常，数值全部通过工具驱动，规则引用到位，符合"状态变更必须走工具"的设计原则。

**但休息系统存在 2 个 P0 级 bug**，导致 `trpg_rest_status` 完全不可用、短休/长休反馈数值错误。这两个 bug 都在 `tools/rest.py` 工具层（字段名/方法名不匹配），状态层逻辑本身正确，修复成本低（各改 1 行）。

**建议优先修复**：
1. `tools/rest.py:60` → `rest_mgr.status()` 改为 `rest_mgr.rest_status()`
2. `tools/rest.py` 短休/长休返回字段名对齐 `rest.py` 实际返回值

修复后可重新跑休息系统测试验证。
