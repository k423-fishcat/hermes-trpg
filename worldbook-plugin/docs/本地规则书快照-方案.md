# 本地规则书快照 + MCP 拉取方案

> 状态：待实施 | 目标版本：v2.9 | 创建日期：2026-08-25

## 一、目标

让 AI 查规则书**不再靠硬编码字符串**，而是从本地规则书快照中按需检索并自动注入到 prompt。

**数据流**：

```
┌──────────────────────┐    一次性拉取（手动 / 脚本）    ┌────────────────────────┐
│  dnd-rules MCP 服务   │ ──────────────────────────► │  rules/builtin/ 本地快照 │
│  (Open5e API 后端)    │    dnd_get_spell / class /    │  (JSON 文件)             │
│                       │    creature / condition       │                          │
└──────────────────────┘                                └──────────┬───────────────┘
                                                                  │
                                                                  │ 运行时只读
                                                                  ▼
                                                       ┌────────────────────┐
                                                       │  RulesBook 类       │
                                                       │  加载 + 检索        │
                                                       └─────────┬──────────┘
                                                                 │
                                                                 │ 按需拼到 system prompt
                                                                 ▼
                                                       ┌────────────────────┐
                                                       │  pre_llm_call 钩子  │
                                                       │  + transform 钩子   │
                                                       └────────────────────┘
```

**关键不变量**：
- 运行时**不依赖** dnd-rules MCP（断网也能玩）
- dnd-rules MCP 只在"构建快照"时使用（一次或定期）
- 所有规则引用都通过 `rule_id` 串联，可追溯

## 五、RulesBook 类设计（`rules/loader.py`）

```python
class RulesBook:
    """规则书快照——运行时只读"""

    def __init__(self, rules_dir: Path):
        self.rules_dir = rules_dir
        self._cache: dict[str, dict[str, dict]] = {}  # {system: {category: {name: data}}}

    def load(self, system: str = "dnd5e") -> "RulesBook":
        """加载指定系统的所有规则分类到内存（懒加载）"""
        ...

    def get(self, system: str, category: str, name: str) -> dict | None:
        """取单条规则"""
        return self._cache.get(system, {}).get(category, {}).get(name)

    def list(self, system: str, category: str) -> list[dict]:
        """列出某分类下所有规则"""
        return list(self._cache.get(system, {}).get(category, {}).values())

    def search(self, query: str, system: str = "dnd5e", top_k: int = 5) -> list[dict]:
        """按 name_zh / name_en / tags 关键词检索"""
        ...

    def list_categories(self, system: str) -> list[str]:
        """列出某系统下所有规则分类"""
        return list(self._cache.get(system, {}).keys())
```

## 七、pre_llm_call 规则注入（`adapter/rules_injector.py`）

```python
class RulesInjector:
    """按当前上下文自动注入相关规则片段"""

    def __init__(self, rules_book: RulesBook):
        self.rules = rules_book

    def inject_for_context(self, prompt: str, system: str = "dnd5e") -> str:
        if not prompt:
            return ""

        # 触发词检测
        triggers = self._detect_triggers(prompt, system)
        if not triggers:
            return ""

        # 查规则
        injected = []
        seen = set()
        for trigger in triggers[:3]:  # 最多 3 条
            results = self.rules.search(trigger, system=system, top_k=1)
            for r in results:
                rid = r["rule_id"]
                if rid in seen:
                    continue
                seen.add(rid)
                injected.append(self._format_rule(r))

        if not injected:
            return ""

        return "## 📖 规则速查（自动注入，来源 PHB）\n" + "\n".join(injected)

    def _detect_triggers(self, prompt: str, system: str) -> list[str]:
        """从 prompt 里检测可能涉及的规则"""
        triggers = []

        # 法术触发
        for spell in self.rules.list(system, "spells"):
            if spell["name_zh"] in prompt or spell["name_en"].lower() in prompt.lower():
                triggers.append(spell["name_en"])

        # 状态效果触发
        for cond in self.rules.list(system, "conditions"):
            if cond["name_zh"] in prompt or cond["name_en"].lower() in prompt.lower():
                triggers.append(cond["name_en"])

        # 关键词触发
        keyword_map = {
            "长休": "long_rest", "短休": "short_rest",
            "死亡豁免": "death_save", "暴击": "critical_hit",
            "豁免": "saving_throw", "优势": "advantage",
        }
        for k, v in keyword_map.items():
            if k in prompt:
                triggers.append(v)

        return triggers

    def _format_rule(self, rule: dict) -> str:
        phb = f"PHB p.{rule.get('phb_page', '?')}" if rule.get('phb_page') else ""
        return f"- **{rule['name_zh']}** ({rule['rule_id']}{', ' + phb if phb else ''}): {rule.get('summary', rule.get('description', ''))[:200]}"
```

def _rule_reference(check_type: str, name: str) -> dict:
    """返回规则引用 {rule_id, text}"""
    from .app_context import get_app
    rules = get_app().rules

    # 尝试从规则书取
    rule = rules.get("dnd5e", "checks", name)
    if rule:
        return {
            "rule_id": rule["rule_id"],
            "text": rule.get("summary", rule.get("description", "")),
            "phb_page": rule.get("phb_page"),
        }

    # Fallback：保留硬编码（不破坏现有逻辑）
    return {
        "rule_id": f"rules.dnd5e.checks.{name}",
        "text": _fallback_string(check_type, name),
        "phb_page": None,
    }

## 十四、与 TRPG-AI-DM 的对比

| 维度 | TRPG-AI-DM | worldbook-plugin v2.9 |
|---|---|---|
| 规则书存储 | `knowledge_base/documents.json`（平铺） | `rules/builtin/{system}/{category}.json`（分类） |
| 数据源 | 手写 `build_system_rule_block()` | dnd-rules MCP / Open5e 拉取（更高质量） |
| 检索 | TF-IDF + BM25（rank_bm25 库） | 简单关键词匹配（v2.9 够用） |
| rule_id | ❌ 无（纯文本） | ✅ 有（可追溯） |
| 集成方式 | system prompt 拼接 | system prompt 拼接 + 工具返回附 ID |
| 多规则系统 | ✅ 4 套 | ✅ 4 套 schema（dnd3r/coc7e/custom 暂空） |

**v2.9 在"数据质量"上超过 TRPG-AI-DM**（Open5e 是真实 SRD），在"检索算法"上**暂时不如**（不引入 rank_bm25 依赖）。
