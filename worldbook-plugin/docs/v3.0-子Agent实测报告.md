## ⚠️ 发现的问题

### P0 级（影响核心功能）

1. **怪物图鉴导入失败**
   - 现象：`trpg_monster_import` 报 `ModuleNotFoundError: No module named 'bestiary_import'`
   - 原因：bestiary_import 模块路径在 v3.0 重构后可能变了，但工具里还在用旧的 import 路径
   - 影响：本地图鉴为空，战斗系统无法实例化怪物
   - 严重度：🔴 P0 — 战斗是核心

2. **缺少创建任务的工具**
   - 现象：子 Agent 搜了 `trpg quest create new` 没找到，只能用 `trpg_state_update` 手动往 `quests.main_01` 写
   - 原因：只有 `trpg_quest_advance`（推进已有的），没有 `trpg_quest_add` / `trpg_quest_create`
   - 影响：DM 无法通过规范工具创建新任务，只能绕路
   - 严重度：🟡 P1

### P1 级（显示/体验问题）

3. **trpg_state_get 总览视图显示 bug（3个）**
   - **背包显示空**：数据中 `player.inventory` 有物品，但摘要视图显示"(空)"
   - **战役名错误**：`campaign_name` 已修改，但摘要顶部仍显示"灰港失踪案"（可能读的是 `campaign.title`）
   - **任务显示为 ID**：任务在摘要中只显示 `main_01: 0`，未渲染标题（`trpg_quest_list` 单独调用是正常的）
   - 原因：总览渲染函数用了旧的字段路径或格式
   - 影响：显示错位，误导 DM，但数据本身正确

4. **ability_scores 和 abilities 字段冗余**
   - 现象：存在两套字段：`player.abilities`（小写键，摘要显示用）和 `player.ability_scores`（大写键，初始用）
   - 影响：DM 需要两套都更新才能一致，容易搞混
   - 建议：统一为一套字段

5. **trpg_check 工具不易被发现**
   - 现象：子 Agent 搜 "skill check ability dice roll" 没找到合适的 trpg 工具，最后用了 `mcp__osg_dice__roll` 掷骰子
   - 原因：`trpg_check` 的 description 可能不够清晰，或者关键词匹配度低
   - 影响：DM 可能不用 trpg_check 做检定，转而用通用骰子，导致检定结果不规范
   - 严重度：🟡 P1

6. **combat_start 传入不存在的怪物静默失败**
   - 现象：传入 `[{"count":2,"name":"哥布林"}]` 后只显示"共0只怪物"，无任何报错或警告
   - 影响：排错困难，DM 不知道哪里出了问题
   - 建议：至少给个 warning 提示"未找到怪物X，已跳过"

### P2 级（优化建议）

6. **战斗缺少一键结算**
   - 现象：启动战斗需要先导入怪物 → 手动加伤害 → 手动推进回合
   - 建议：参考 TRPG-AI-DM 的 `combat_round` 一键结算工具（AI 只传动作和目标）

7. **trpg_monster_search 中文支持差**
   - 现象：搜"哥布林"没结果，英文搜 "goblin" 才行
   - 建议：加中文别名映射

## 📊 总体评估

**可用度：7/10**

核心状态读写没问题（state_get/state_update 工作正常），但战斗系统有阻塞性问题（怪物导入失败），导致战斗硬约束、战斗注入等都没测到。

**最紧急的修复：**
1. 🔴 修怪物图鉴导入流程（bestiary import）
2. 🟡 加 `trpg_quest_add` 工具（创建新任务）
3. 🟡 修 `trpg_state_get` 总览显示 bug（背包空 + 标题不更新）
4. 🟡 优化 `trpg_check` 工具描述，让 AI 更容易搜到

修完 P0 + P1 后，可以再跑一次完整的战斗测试，验证硬约束是否有效。
