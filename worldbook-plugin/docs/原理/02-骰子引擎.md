# 02 — 骰子引擎原理

> dice.py：所有掷骰逻辑的集中入口（11 个函数，纯 Python stdlib）

---

## 一、为什么集中

v2.5 之前，6 个文件（combat/check_engine/characters/rest/spells/tools）里有 13 处
`import random` + `random.randint(...)` 内联调用。v2.6 集中到 `dice.py`：

- 统一实现，修一处全生效
- 结构化返回（total/rolls），便于工具格式化
- 零外部依赖（不引 Go 进程 / FastMCP server）

---

## 二、函数总览

| 类别 | 函数 | 用途 |
|------|------|------|
| 基础 | `roll_dice(n, s)` | 投 N 颗 M 面，返回 list |
| 表达式 | `roll(expr)` | 解析骰子表达式 |
| D20 | `roll_d20(adv, dis)` | 优势/劣势取高低 |
| 伤害 | `roll_damage(expr, mod, crit)` | 武器伤害，暴击翻倍 |
| 治疗 | `roll_healing(expr, mod)` | 法术治疗 |
| 命中骰 | `roll_hit_dice(sides)` | 单颗命中骰 |
| 命中骰 | `roll_hit_dice_total(expr, con_mod)` | 短休 N 颗 |
| 属性 | `roll_ability_scores(method)` | DnD 六项属性 |
| 先攻 | `roll_initiative(dex_mod)` | 1d20 + 调整 |
| COC | `coc_check(skill, bonus, penalty)` | d100 检定 |
| 格式化 | `format_roll_result(result)` | 可读输出 |

## 三、表达式解析 `roll(expr)`

**支持语法：**

| 语法 | 例子 | 说明 |
|------|------|------|
| 基础 | `2d6` / `d20` | N 颗 M 面 |
| 加减 | `d20+5` / `3d6-2` | 修正值 |
| 多组 | `2d6+1d4+3` | 混合骰子 |
| 优势/劣势 | `adv` / `dis` | 2d20 取高/低 |
| 留高/留低 | `4d6kh3` | DnD 属性骰 |
| 百分骰 | `d100` / `d%` | COC |

**解析流程：**

```
roll("2d6+1d4+3")
  ├── 识别 adv/dis/d100 快捷语法
  ├── 正则 _TERM_RE 逐项切分（带符号）
  │   ├── 骰子项：count/d/sides (+ kh/kl 后缀)
  │   └── 常数项：带符号
  ├── 逐项掷骰累加
  └── 单 d20 时标记 nat_20/nat_1
```

**注意**：负数常数 `1d8-2` 的符号解析（const_str 自带符号）。

---

## 四、D20 与优势/劣势

```
roll_d20(advantage=True)
  ├── 投 2 颗 d20
  └── 取高（优势）/ 取低（劣势）
```

返回 `{nat_roll, all_rolls, is_advantage, is_disadvantage, is_crit_success, is_crit_fail}`。

`check_engine` 和 `spells`（专注豁免）都走这个统一入口。

---

## 五、伤害与暴击

```
roll_damage("1d8", modifier=3, crit=True)
  ├── crit → 骰子数翻倍（2d8）
  └── total = sum(rolls) + modifier
```

暴击只翻倍骰子，不加倍 modifier（D&D 规则）。

---

## 六、命中骰（D&D 短休/升级）

**短休** `roll_hit_dice_total("2d10", con_modifier=2)`：
- 每颗骰子恢复 `roll + con_mod`（PHB 实际规则，无下限钳制）
- v2.8 修复：移除之前的伪规则 `max(1, roll + con_mod)`，1 HP 角色不会"凭空"多出 1 点

**升级** `roll_hit_dice(sides)`：
- `characters.py` / `tools.py` 升级 HP 用，替代内联 randint

---

## 七、COC 7e 检定 `coc_check`

```
coc_check(skill_value=50, bonus_dice=0, penalty_dice=0)
  ├── 个位骰 d10
  ├── 十位骰（基础 + 奖励/惩罚骰数）
  ├── 奖励骰 → 取最小十位 / 惩罚骰 → 取最大十位
  ├── 0 → 100（COC 规则）
  └── 成功等级：
      大成功(1) < 极难(≤skill/5) < 困难(≤skill/2) < 成功(≤skill) < 失败 > 大失败(100)
```

---

## 八、错误处理

- 非法表达式 → `ValueError`（数量/面数越界、无法解析）
- 上限保护：骰子 ≤1000 颗，面数 ≤10000

---

## 九、使用方

| 调用方 | 用途 |
|--------|------|
| `check_engine.py` | d20 检定（roll_d20）、COC 检定（coc_check） |
| `combat.py` | 先攻（roll_initiative） |
| `spells.py` | 治疗（roll_healing）、专注豁免（roll_d20） |
| `rest.py` | 短休命中骰（roll_hit_dice_total） |
| `characters.py` / `tools.py` | 升级 HP（roll_hit_dice） |
