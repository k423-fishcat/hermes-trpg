# 10 — 模组导入原理

> adventure/ 包：多格式检测 → 中间模型 → 导入运行时系统

---

## 一、架构

```
adventure/
├── models.py          AdventureModule 中间模型
├── loader.py          detect_format / load_module / import_module / export_module
└── formats/
    ├── native.py      adventure.json 原生格式解析
    └── zim_wiki.py    Zim Desktop Wiki 目录解析
```

**设计**：格式与核心解耦，加新格式 = 新建一个 `formats/xxx.py` 解析器。

---

## 二、格式自动检测（detect_format）

```
detect_format(path)
  ├── .json 文件 → "native"
  ├── 目录有 notebook.zim → "zim_wiki"
  ├── 目录有 ≥3 个 txt 且头部含 "Content-Type: text/x-zim-wiki" → "zim_wiki"
  └── 否则 → None
```

---

## 三、中间模型（AdventureModule）

```python
@dataclass
class AdventureModule:
    id, name, system, version, author, description
    entries: List[WorldBookEntryData]   # 世界书条目
    npcs: List[NPCData]                 # NPC
    quests: List[QuestData]             # 任务
    encounters: List[EncounterData]     # 遭遇
    world_flags: Dict                   # 世界标记
    opening_title / opening_summary / opening_hook   # 开场章节
    source_format
```

统一的中间表示，各种格式都解析成它，后续导入逻辑与格式无关。

---

## 四、加载流程（load_module）

```
load_module(path, module_id, module_name)
  ├── detect_format
  ├── native → parse_native_adventure
  ├── zim_wiki → parse_zim_directory
  └── 覆盖 module_id/name
```

---

## 五、导入流程（import_module）— 核心

```
import_module(mod, worldbook_store, state_mgr, quest_mgr, npc_mgr, chron_mgr)
  ├── 1. 世界书条目：批量导入（跳过内容 <20 字的）
  ├── 2. NPC：逐个创建 + 填描述/态度/位置/已知信息/日程
  ├── 3. 任务：add_quest（含步骤/前置/奖励）
  ├── 4. 遭遇：存到 state.world.encounters
  ├── 5. 世界标记：存到 state.world.flags
  └── 6. 开场章节：自动创建 + 记录开场钩子
  → 返回统计 {entries_imported, npcs_imported, quests_imported, ...}
```

---

## 六、模组管理器（modules.py）

`ModuleManager` 管理模组生命周期：

```
list_available()  → 扫描 data/adventures/ 目录
activate(id)      → 加载 + 导入 + 记录 active_modules
deactivate(id)    → 从激活列表移除（数据保留）
```

**激活状态**存在 `state.campaign.active_modules`。

## 八、导出（export_module）

`export_module_json` 把中间模型转回原生 adventure.json 格式，
方便编辑后重新导入或分享。

---

## 九、导入链路

```
玩家/AI 调 trpg_module_activate("lmop")
  → ModuleManager.activate
  → adventure.loader.load_module（格式检测 + 解析）
  → adventure.loader.import_module
  → 世界书/NPC/任务/遭遇/世界标记/开场章节 全部就位
  → 玩家可以开跑了
```
