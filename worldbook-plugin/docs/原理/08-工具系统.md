## 二、ToolRegistry 装饰器

```python
class ToolRegistry:
    def __init__(self, ctx):
        self._ctx = ctx
        self._tools = []

    def tool(self, name, description, schema, emoji="", toolset="trpg"):
        def decorator(func):
            self._tools.append({...})
            return func
        return decorator

    def register_all(self) -> int:
        for t in self._tools:
            self._ctx.register_tool(**t)
        return len(self._tools)   # 真实计数
```

**加工具 = 写一个 `@reg.tool(...)` 装饰器 + handler 函数**，无需改注册逻辑。

## 三、注册流程

```python
# __init__.py
app = get_app()                      # 统一容器（14 service）
n = register_all_tools(ctx, app)     # 82 个工具一次注册
logger.info(f"注册了 {n} 个工具")
```

```python
# tools/__init__.py
def register_all_tools(ctx, app) -> int:
    reg = ToolRegistry(ctx)
    state_tools.register(reg, app.state)      # 2
    narrative.register(reg, app.chronicle, app.quests, app.npcs, app.clock)  # 21
    bestiary.register(reg, app.bestiary)      # 5
    combat.register(reg, app.combat)          # 9
    ...（共 14 组）
    return reg.register_all()                 # = 82
```

## 五、handler 模式

每个工具 handler 是一个函数：`(args: dict) -> str`。

```python
@reg.tool("trpg_check", "DnD 5e 检定", schema=CHECK_SCHEMA, emoji="🎯")
def check(args):
    from ..check_engine import roll_check, format_check_result
    try:
        result = roll_check(state, ...args...)
        return format_check_result(result)
    except Exception as e:
        return f"❌ 检定失败: {e}"
```

返回字符串直接作为工具结果（AI 可读）。错误返回 ❌ 前缀，不抛异常。

        "required": ["check_name"],
    },
}

## 七、工具与 AppContext

工具通过 `app_context.get_app()` 获取所有 service，不再各自持有 singleton：

```python
# tools/check.py
def register(reg, state, chron):
    @reg.tool(...)
    def check(args):
        # 直接闭包捕获注入的 state/chron
```

**收益**：测试时可注入 mock service；无全局状态污染。

## 十、Hermes kwargs 兼容（2026-08-26）

Hermes 调用工具 handler 时传入 `task_id` / `session_id` 等系统 kwargs，
而所有 handler 签名是 `(args: dict)`。`ToolRegistry.register_all()` 在注册时
用 `_wrap_handler` 包一层，过滤系统参数：

```python
@staticmethod
def _wrap_handler(handler):
    def wrapper(args, **_kwargs):
        return handler(args)
    return wrapper
```

修复前所有 82 个工具在 Hermes 下都会抛
`TypeError: ... got an unexpected keyword argument 'task_id'`（P0，见 v3.0 实测报告）。
