# 09 — 世界书与检索原理

> store.py（数据模型）+ retriever.py（双后端检索）+ interactions.py（交互点）

---

## 一、世界书数据模型

```python
@dataclass
class WorldBookEntry:
    id: str
    title: str
    keys: List[str]        # 关键词
    category: str          # 地点/NPC/物品/组织/剧情/怪物/规则/...
    content: str
    extras: Dict           # 扩展数据（含 interactions 交互点）
    priority: int          # 优先级（排序用）
    enabled: bool
    worldbook: str         # 所属世界书
    created_at / updated_at
```

存储：`data/worldbooks/*.json`，每本一个文件（原子写入）。

---

## 二、双后端检索

`WorldBookRetriever` 支持两种后端，自动降级：

```
search(query, worldbooks, categories, limit)
  ├── backend == "openviking"？
  │   ├── _search_viking（向量检索）
  │   │   ├── 构造增强 query（"<query> <世界书> 跑团世界书设定"）
  │   │   ├── 调用 viking_search（Hermes 内置 / HTTP API fallback）
  │   │   ├── 按 score ≥ min_score 过滤
  │   │   ├── 用标题回查本地条目（拿到完整内容）
  │   │   └── 本地没有 → 用 viking 摘要构造临时条目
  │   └── 失败 → 降级本地
  └── backend == "local" → _search_local
```

### 本地关键词打分（store.search_local）

```
评分规则：
  标题精确匹配    +100
  标题包含 query  +50
  query 含标题    +60
  关键词精确      +80
  关键词在 query  +45
  query 含关键词  +30
  内容出现        +10
```

中文适配：不做分词，直接子串匹配（双向：条目含 query 或 query 含条目）。

## 三、注入格式化

`format_for_injection` 把检索结果转成 markdown 注入：

```
## 世界书相关设定

### 灰港（地点）
灰港是剑湾北端的港口小镇...

**可交互点：**
  🎲 撬开仓库门 — 巧手 DC15（隐藏，需 察觉 DC10 发现）
     ✅ 成功进入仓库
```

---

## 四、交互点系统（interactions）

世界书条目可在 `extras.interactions` 里嵌入预设交互点：

```json
{
  "trigger": "撬开仓库门",
  "type": "skill",
  "check": {"skill": "巧手", "ability": "dex", "dc": 15},
  "hidden": true,
  "discovery_skill": "察觉",
  "discovery_dc": 10,
  "outcomes": {
    "success": "成功进入仓库",
    "fail": "撬锁失败，锁芯卡住"
  }
}
```

**作用**：让探索检定的 DC 和后果有据可依，不是 AI 临场编。

## 五、配置

| 配置 | 默认 | 作用 |
|------|------|------|
| `search_backend` | openviking | 检索后端 |
| `max_entries` | 5 | 每次注入条目数 |
| `min_similarity` | 0.6 | 最低相似度 |
| `enabled_books` | [...] | 启用的世界书 |
| `cache_ttl` | 60 | 检索缓存秒数 |

---

## 六、检索缓存

`injector._cache`：query → (result, timestamp)。TTL 内同 query 直接返回，
避免每轮重复检索 OpenViking（有延迟）。

---

## 七、世界书管理器（manager.py）

提供 AI 工具 / 斜杠命令操作世界书：
- 条目增删改查（add/edit/delete/list/search）
- 书籍启停（enable_book）
- 导入/导出（import_book/export_book，导出走原子写）
