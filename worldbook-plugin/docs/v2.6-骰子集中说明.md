# v2.6 骰子集中更新说明

## 一句话

13 处内联 `random.randint` → 集中到 `worldbook-plugin/dice.py`。纯 Python stdlib，零外部依赖。

## dice.py 提供 11 个函数

- `roll_dice(n, s)` — 投 N 颗 M 面
- `roll(expr)` — 解析表达式（`2d6+3` / `4d6kh3` / `adv` / `dis` / `d100`）
- `roll_d20(adv, dis)` — D&D d20 含优势劣势
- `roll_damage(expr, mod, crit)` — 武器伤害
- `roll_healing(expr, mod)` — 法术治疗
- `roll_hit_dice(sides)` — 单颗命中骰
- `roll_hit_dice_total(expr, con_mod)` — 短休 N 颗
- `roll_ability_scores(method)` — DnD 属性
- `roll_initiative(dex_mod)` — 先攻
- `coc_check(skill, bonus, penalty)` — COC 7e
- `format_roll_result(result)` — 格式化输出

## 迁移 13 处

| 文件 | 旧 | 新 |
|------|---|---|
| combat.py × 3 | `random.randint(1,20) + bonus` | `roll_initiative(dex_modifier=bonus)["total"]` |
| check_engine.py × 5 | 5 处 d20 | `roll_d20(adv, dis)["nat_roll"]` |
| rest.py × 1 | 短休循环 | `roll_hit_dice_total("NdM", con_mod)` |
| spells.py × 1 | 治疗循环 | `roll_healing("NdM", heal_mod)` |

| characters.py × 1 | 升级 HP | `roll_hit_dice(sides)` |
| tools.py × 1 | 升级 HP | `roll_hit_dice(sides)` |
| interactions.py | 死 import random | 删除 |

## 不用外部 dice MCP

旧文档声称用了 `trpg-dice MCP`（FastMCP）和 `osg-dice MCP`（Go 编译），实际插件代码 0 引用。结论：

- 不起 Go 进程（多一个故障点）
- 不起 FastMCP server（成本远大于 ~440 行 Python）
- 自研 dice.py 零依赖好测试

## 验证

```python
from dice import roll, roll_d20, roll_damage
roll('2d6+3')              # {total: 8, ...}
roll('4d6kh3')             # {total: 14, kept: [5,4,4]}
roll_d20(advantage=True)   # {nat_roll: 18}
roll_damage('1d8', 3, True)  # {total: 12, crit: True}
```
